BETTER LINE LIMO LLC — LUXURY WEBSITE UPDATE

This is a static promotional PWA/demo. NOT a payment processor or production booking system.

INSTALL TO EXISTING GITHUB REPOSITORY:
1. Open the repository, select Add file > Upload files.
2. Upload index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, and the assets folder (with 7 JPG images).
3. Commit changes, then reload your published site.
4. Avoid uploading any customer details, insurance policy, VINs, secret keys or passwords.

WHAT IS INCLUDED:
- 3 slow-changing hero images (7-second hold, 2-second fade).
- Black-and-gold mobile-ready design.
- Fleet cards with illustrative images: Cadillac Escalade ESV, Lincoln Navigator, Chevrolet Suburban, GMC Yukon XL.
- Luxury services and brand messaging.
- Customer booking request form, draft by email or copy to clipboard.
- PWA install support.

IMPORTANT LIMITS:
- No real booking confirmation, central database, Stripe integration or payments.
- Company email demo settings save only in one browser; they do not publish to visitors.
- Vehicle photos are AI-generated marketing illustrations, not actual fleet photos. Replace with real licensed car photos before launch.
- Avoid implying that the business operates private aircraft; imagery is illustrative.

NEXT PHASE: Verify fleet and rates, collect official business contact details, implement secure booking backend and Stripe Checkout, then test with real-world constraints.
